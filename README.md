## ✨ Features

### 🀄 1. Dual Gameplay Modes
* **Vita Mahjong Mode (Pairs)**:
  - Free, unblocked identical tiles dissolve immediately upon selection without tray friction.
  - Zero pressure, meditative pace.
* **Tile Club Mode (Triads)**:
  - Match-3 mechanic utilizing a 7-slot sorting tray with auto-sorting.
  - Clear triads or manage capacity before tray overflow.

### 👓 2. Senior-First Accessibility
* **1-Click Senior View (`[Aa]`)**:
  - Dynamically scales tile dimensions by **+25%** (from $68 \times 88\text{px}$ to $85 \times 110\text{px}$).
  - Enlarged typography and high-contrast vector symbols with $> 11:1$ contrast ratio exceeding **WCAG AAA** standards.
* **Clear State Indicators**:
  - Unblocked playable tiles have elevated drop shadows and crisp contours.
  - Occluded/blocked tiles display a lock badge (`🔒`) and visual desaturation.
  - Golden aura highlight (`#D4AF37`) illuminates active selections and hint targets.

### 📐 3. Guaranteed 100% Solvability
* Engineered using a mathematical **Reverse-Construction Generation Engine**:
  - Every level layout is built backwards by simulating valid, unoccluded plays.
  - Eliminates unwinnable board states and deadlocks before the first move is made.

### 🔔 4. Pure Web Audio Procedural Synthesis
* Zero external `.mp3` or `.wav` dependencies.
* **Acoustic Tuning**: Toggle between natural **432 Hz Pythagorean harmonic scale** and standard **440 Hz Concert Pitch**.
* **Platonic Year Meditation Gong**:
  - Harmonic morning fundamental (172.08 Hz) and deep evening resonance (110.0 Hz).
  - 5 natural acoustic overtones ($1.47\times, 2.09\times, 2.56\times, 3.12\times, 4.2\times$) with smooth exponential decay.
* **Gentle Non-Startle Hums**: Soft low-pass 196 Hz G3 feedback for occluded taps.

### 💻 5. Responsive Cross-Device Design
* **Desktop ($\ge 1024\text{px}$)**: Fluid 3-Column Sanctuary Layout:
  - **Left**: Botanical Field Guide (binomial classification, ecological lore).
  - **Center**: 2.5D Isometric tile sanctuary stage.
  - **Right**: Prahar Solar Clock and matched reflections gallery.
* **Mobile / Tablet ($< 1024\text{px}$)**: Concentrated single-column layout with quick-action bottom HUD.
